# Cloudstro

**Astro + Cloudflare Workers** admin dashboard framework for building enterprise-grade administration panels with zero cold starts and edge computing scalability.

## Quick Start

```bash
git clone https://github.com/ribalhu/cloudstro.git
cd cloudstro
pnpm install
pnpm dev
```

Server runs at `http://localhost:4321`

## Technology Stack

- **Framework**: Astro 6.0 (zero JavaScript by default)
- **Styling**: Tailwind CSS 4.2
- **Deployment**: Cloudflare Workers (serverless edge)
- **Runtime**: Node.js 22.12.0+
- **Package Manager**: pnpm

## Key Features

🔐 JWT Authentication • 📧 Email Integration • 👥 User Management • 🎨 UI Components • ⚡ Edge Computing • 📱 Responsive Design

## Development

```bash
pnpm dev              # Start dev server
pnpm build            # Production build
pnpm test             # Run tests
pnpm version:*        # Versioning (patch/minor/major)
```
